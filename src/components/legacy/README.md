# Archived vector motif

`LegacyVectorCard` preserves the original blue Figma-style selection border and corner handles using the existing `.vector-card` styles in `src/index.css`.

It is intentionally not rendered on the website. Rounded cards remain the current default for FAQs, pricing, and deliverables. Arek may choose a new placement for the vector motif later; do not reintroduce it automatically.

FAQs open on click or keyboard activation, never on hover. Their collapsed answers remain in the HTML.
